# Chat-Application-Java

A simple chat application implemented using Java Sockets that allows multiple clients to communicate through a central server.

## Features
- Client-server architecture
- Support for multiple clients
- Simple command-line interface
- Real-time message broadcasting

## How to Run

1. First, compile all Java files:
```bash
javac Server.java
javac Client.java
```

2. Start the server:
```bash
java Server
```

3. In separate terminal windows, start multiple clients:
```bash
java Client
```

## Usage
- When you start a client, you'll be prompted to enter your username
- Type your messages and press Enter to send
- Type 'exit' to quit the chat

## Requirements
- Java 8 or higher
